# 3D-експедиція: таємниця цифрової лабораторії

Інтерактивний навчальний квест для учнів **9 класу НУШ** за матеріалами § 4.1 «Тривимірна графіка. Принципи тривимірного моделювання» (наданий фрагмент підручника).

## Що є в квесті

1. **Вхід до лабораторії** — поняття рендерингу, 3D-моделі й зображення.
2. **Де потрібне 3D?** — сфери застосування тривимірних моделей.
3. **Інструменти фахівця** — переглядач, редактор і програма для рендерингу.
4. **Будова мешу** — вершина, ребро, грань; елементи куба.
5. **Пульт моделювання** — власноруч обертати тривимірну модель, обирати примітив і змінювати масштаб.
6. **Фінальна перевірка** — вибір 3D-технологій для практичних завдань.

Загальний бал: **100**. Час: **25–35 хвилин**. За неправильні відповіді бали не знімаються — можна спробувати ще раз. Місії відкриваються послідовно. Прогрес зберігається локально в браузері. Наприкінці учень завантажує текстовий звіт.

## Опублікувати на GitHub Pages

1. Створіть **New repository**, наприклад `3d-ekspedytsiia-9` (Public).
2. Завантажте `index.html` та `README.md` у корінь репозиторію через **Add file → Upload files** (або посилання `uploading an existing file`). Не завантажуйте ZIP замість файлів.
3. Натисніть **Commit changes**.
4. Відкрийте **Settings → Pages → Build and deployment**.
5. Виберіть **Deploy from a branch → main → / (root)** та натисніть **Save**.
6. Посилання буде такого вигляду: `https://ВАШ-ЛОГІН.github.io/3d-ekspedytsiia-9/`.

## Для вчителя

Рекомендовано: 3–5 хвилин вступу; 25–30 хвилин самостійної роботи; 5–7 хвилин рефлексії. Можна запропонувати учням обговорити різницю між 3D-моделлю, рендерингом та фізичним 3D-друком.

**Збір результатів:** сайт статичний, не має сервера чи журналу оцінок. Результати НЕ надсилаються вчителю автоматично. Учень надсилає завантажений звіт у Classroom, електронною поштою або в інший погоджений спосіб. ПІБ у звіті необов'язкові, вводяться учнем самостійно.

**Працює без сторонніх бібліотек, CDN, API та облікових записів.** 3D-переглядач створено на HTML Canvas і JavaScript, тому для використання не потрібен Blender чи окреме 3D-ПЗ.
